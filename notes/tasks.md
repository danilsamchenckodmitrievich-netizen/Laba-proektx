# База задач Аксиоры — версия 1

Это подготовка данных для будущего раздела «Практика и решение задач».

| Файл | Назначение |
|---|---|
| `data/tasks/catalog.json` | Публичные условия и предметы на русском и английском |
| `schemas/task-catalog.schema.json` | JSON Schema 2020-12 каталога |
| `backend/data/task-solutions.json` | Эталоны, ограничения, шаги и подсказки будущего FastAPI |
| `schemas/task-solutions.schema.json` | JSON Schema эталонов |
| `assets/tasks/*.svg` | Адаптивные чертежи с viewBox |
| `tools/validate_tasks.py` | Проверка структуры, уникальности ID, связей и иллюстраций |

## Правила данных

- ID задач постоянные, латиницей; связь с эталоном — по `task_id`. Правка текста не меняет ID.
- `schema_version` равен 1. Несовместимая смена структуры требует новой версии.
- У задачи есть предмет, тема, класс, сложность, время, навыки и источник.
- Сложность: `beginner`, `intermediate`, `advanced`; интерфейс переводит эти идентификаторы.
- `title`, `topic`, `statement`, `alt`, объяснения и подсказки содержат `ru` и `en`.
- Формулы в условии заключены в `\(` и `\)`. Отдельные поля `latex` — без разделителей.
- Условия не являются HTML. Интерфейс должен экранировать текст и использовать KaTeX без доверенного HTML.
- Публичная запись не содержит ответов, подсказок и решений; неизвестные поля отклоняются схемой.
- `answer.values` — канонические строки для будущего SymPy-парсера, а не исполняемый Python-код.
  `solution_set` — полный набор корней, порядок несущественен; `quantity` — значение с единицей.
- Допуск количественного ответа абсолютный, в указанной единице; стартовые ответы точные.
- `variables` задаёт область значений и исключения. Сокращение дроби не отменяет запрет нулевого знаменателя.
- `method: reasoning` у доказательства требует анализа аргументации; это не сертификат SymPy.
- Эталон не ограничивает ученика одним способом решения: проверяющий должен учитывать эквивалентные рассуждения.

В комплекте 9 оригинальных задач: по три уровня для алгебры, геометрии и физики.
Четыре SVG-чертежа условные; в доказательстве нет заранее отмеченного прямого угла.

## Добавление и проверка

1. Добавьте условие и эталон с тем же ID, заполните обе локали.
2. При необходимости добавьте SVG в `assets/tasks/` и словесное описание.
3. Установите зависимости: `python3 -m pip install -r tools/requirements-dev.txt`.
4. Выполните `python3 tools/validate_tasks.py` и `python3 -m unittest discover -s tests -p 'test_*.py'`.

Эти проверки также выполняются в GitHub Actions. Каталог пока не подключён к меню.

## Публикация

В `_config.yml` backend исключён из стандартной Jekyll-сборки GitHub Pages.
При переходе на Vite публичный артефакт должен содержать только приложение, публичный каталог
и иллюстрации; `backend/` развёртывается отдельно в Hugging Face Space.

Git-репозиторий публичный: разделение файлов не делает эталоны секретными. Эта база — для практики.
Для контрольных с закрытыми ответами нужны непубличное хранилище и проверка прав;
действующие тесты учителя в Supabase не заменяются этими JSON.
Space не должен постоянно хранить фотографии учеников: файлы обрабатываются временно.
